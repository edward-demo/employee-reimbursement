# UC-013: Admin View Reimbursement Reports

## Primary Actor
Admin

## Goal
Analyze reimbursement totals by department and reimbursement category.

## Source Evidence
- src/app/components/AdminDashboard.tsx

## Trigger
The admin selects the Reports tab or reviews report charts in the admin portal.

## Main Flow
1. The system displays medicine reimbursement totals by department.
2. The system displays optical reimbursement totals by department.
3. The system displays approved counts and total amounts in chart form.
4. The admin compares category and department-level reimbursement patterns.

## Postconditions
The admin can use the report view for monitoring and decision support.
