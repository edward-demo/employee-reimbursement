# UC-003: Employee View Profile

## Primary Actor
Employee

## Goal
View personal employment information used by the reimbursement system.

## Source Evidence
- src/app/components/EmployeeDashboard.tsx

## Trigger
The employee selects the Profile tab.

## Main Flow
1. The system displays the employee's full name.
2. The system displays employee ID, designation, department, and email.
3. The employee reviews profile information.

## Postconditions
The employee has confirmed the profile information visible in the portal.
